# 游戏设计文档 — 火纹式单场战斗 DEMO

> 状态：**M1 设计定稿 ✅**（2026-09-04）。§2~§9 全部已确认，进入 M2 工程实现。
> 数值与公式均为初版占位，以"先能玩、再调平衡"为原则。

## 1. 概述

- 类型：回合制战棋（SRPG），参考火焰纹章系列
- 一句话：一张 20×30 六边形地图上，我方 10 人部队歼灭敌方 40 人守军的单场战斗
- 体验目标：火纹式决策手感——查看移动范围 → 战斗预报 → 权衡风险 → 落子

## 2. 核心循环（已确认 2026-09-04）

- 回合制：玩家阶段 → 敌方阶段 → 回合数 +1
- 单位行动 = 完整行动序列：移动 → 行动（攻击/法术/道具/待机）→ 再移动（单位支持时）→ 确认朝向 → 结束，详见 §4.8；已行动单位置灰
- 全部单位行动完毕自动进入敌方阶段，也可手动提前结束回合
- 胜利条件：敌方全灭
- 失败条件：我方全灭，或领主（主角）阵亡（见 §5.2）
- 无回合上限，战斗进行到分出胜负为止

## 3. 地图（已确认 2026-09-04）

- **正六边形网格**，尺寸 20×30（宽×高，配置项）
- 密度已验证：10+40=50 单位 / 600 格 ≈ 8.3%，落在火纹典型区间（7%~10%）
- 六边形朝向（尖顶/平顶）与坐标系（推荐轴坐标）为实现细节，工程初始化时定
- 距离、射程、移动范围均以六边形步数计
- 地形 4 种，**数据驱动定义，保留扩展性**（新增地形 = 新增一条配置，无需改代码）：

| 地形 | 效果 | 移动消耗 |
| --- | --- | --- |
| 平原 | 无 | 1 |
| 森林 | 回避 +20，防 +1 | 2 |
| 山 | 不可通行 | - |
| 基地 | 防 +2，回避 +20，回合开始恢复 10% 最大 HP | 1 |

- 基地效果**对任何驻守单位生效**（已确认）：北端布 1 处供敌方 BOSS 驻扎；我方占领后同样受益，形成"夺基"战术
- 敌方 40 人建议分 6~8 组待机型布防，玩家推进时逐组接敌（分组细节见 §5）；地图边缘含**增援点**（敌方增援刷新位置，见 §6）
- 关卡用静态 TS 配置文件定义，不做地图编辑器

## 4. 战斗机制（已确认 2026-09-04）

### 4.1 单位属性（6 项）

| 属性 | 作用 |
| --- | --- |
| HP | 生命值，归零阵亡 |
| 攻 | 伤害基数 |
| 防 | 减伤（受地形防加成） |
| 速 | 追击判定依据 |
| 技 | 命中基数 |
| 运 | 回避基数 |

### 4.2 伤害类型 × 护甲类型（已确认 2026-09-04）

- **取消武器三角克制系统**，改为伤害类型对护甲类型的加成补正
- 护甲 4 类：无 / 轻 / 中 / 重；伤害 4 类：穿刺 / 挥砍 / 钝击 / 法术
- 加成矩阵（已确认，每行每列恰好一个 ×1.25 与一个 ×0.75，乘算在最终伤害上）：

| 伤害 \ 护甲 | 无甲 | 轻甲 | 中甲 | 重甲 |
| --- | --- | --- | --- | --- |
| 穿刺 | **×1.25** | ×1.0 | ×1.0 | ×0.75 |
| 挥砍 | ×1.0 | **×1.25** | ×0.75 | ×1.0 |
| 钝击 | ×1.0 | ×0.75 | **×1.25** | ×1.0 |
| 法术 | ×0.75 | ×1.0 | ×1.0 | **×1.25** |

- 设定理由：穿刺直入血肉但被板甲弹开；挥砍断皮甲但锁链卸刀；钝击砸垮锁环但软衬吸能；法术侵彻板甲而无甲者天生魔抗
- 矩阵整体为**纯配置数据**：克制倍率、行列增删（新伤害类型/新护甲类型）都只改配置文件，不改代码；调试平衡时只调配置。矩阵同样可被特性改写（如"破甲"特性无视克制）
- 伤害类型的最终来源是**攻击时选择的技能**（§4.9），兵种/装备决定可用技能池；护甲类型由兵种模板携带（§5 落地），可被辅助法术效果临时覆盖（§4.10）
- 现有草案中钝击/法术来源将在技能池设计中补齐（如剑盾战士的盾突=钝击、法系兵种的法术）

### 4.3 战斗公式（已确认 2026-09-04）

- 伤害 = floor(max(攻 − 防 − 地形防, 0) × 甲伤矩阵系数)
- 回避 = 运 ×3 + 地形回避
- 命中率 = clamp(50 + 技 ×5 − 敌方回避 + 部位命中补正 − 距离命中惩罚, 5, 100)（武器克制已移除，不再影响命中）
- 追击：速度差 ≥4 时速度快的一方多攻击一次
- 结算顺序：攻方攻击 → 守方反击（守方射程覆盖攻方位置才反击）→ 追击方攻击
- **反击技能选择**（已确认 2026-09-04）：守方有多个技能射程覆盖攻方位置时，取期望伤害最高者（与 §6 AI 择优一致）
- 实际结算按命中率掷随机数；战斗预报显示概率而非结果

### 4.4 射程与距离惩罚（已确认 2026-09-04）

- 射程统一建模为区间 `[最小射程, 最大射程]` = **基础值 + 修正值**
  - 基础值：兵种/技能配置——近战 `[1,1]`，弓手基础 `[2,2]`
  - 修正值：走 §4.7 特性修正管线；来源包括武器/装备加成、属性条件加成（如"攻 ≥9 时射程 +1"，阈值规则可配，具体待定）、特性、技能特效、状态
- **距离命中惩罚**：命中 −15 × max(0, 攻击距离 − 基础最大射程)
  - 基础射程内无惩罚；每超出 1 格命中 −15（打 3 格 −15，打 4 格 −30）
  - 近战恒为 0，规则自然退化无需特判
- 弓手最小射程保持 2：相邻格仍是攻击/反击死角（贴脸克制不变）
- 每格惩罚值（−15）为配置项；战斗预报显示当前攻击距离与惩罚值

### 4.5 战斗预报（已确认 2026-09-04）

- 选中攻击目标时显示：双方预计伤害 ×攻击次数、命中率（含部位/距离/矩阵明细）、是否被反击及反击数据

### 4.6 明确不做

- 暴击/必杀、武器耐久

### 4.7 朝向与部位系统（已确认 2026-09-04）

**基础规则层**（默认生效，全部可被特性修正）：

- 每个单位恒有一个朝向，指向相邻 6 格之一
- 朝向控制（已确认 2026-09-04）：行动序列末尾有"确认朝向"步骤，**默认朝向 = 最后一次移动或攻击的方向，玩家可手动调整**；此为基础规则，可被特性改写
- 以**守方朝向**为基准，攻击者所在格分三区：
  - 正面 3 格：朝向格 + 左右紧邻两格（180° 扇面）
  - 侧面 2 格：侧后方两格
  - 背面 1 格：正对背后
- 部位补正默认值：

| 攻击来自 | 命中 | 伤害 |
| --- | --- | --- |
| 正面 | — | — |
| 侧面 | +10 | — |
| 背面 | +25 | +3 |

- 远程攻击（射程 2）同样按守方朝向判部位；**远程部位判定**（已确认 2026-09-04）：攻方相对守方的方向量化到最近 6 方向后，再按正/侧/背扇区判定
- 被攻击**不自动转向**（默认）
- 反击、追击套用同一部位规则（默认）
- AI 同样利用部位补正择优攻击
- UI：单位绘制朝向箭头，战斗预报显示部位及补正

**修正层——特性系统**（扩展机制）：

- "特性"是技能/天赋/道具的统一抽象，挂在单位身上，战斗结算时逐条应用
- 基础规则层的每一项（补正数值、是否自动转向、反击是否套用等）都可被特性改写
- 特性类型举例：
  - 数值改算：盗贼"背刺"——背面伤害加成由 +3（加算）改为 ×1.5（乘算）
  - 行为改写："警觉"——被攻击时自动转向攻击者，侧/背攻击对其失效
  - 补正减免："沉稳"——受到的部位命中补正减半
- 结算管线：取基础规则 → 依攻守双方特性逐条修正 → 得最终结算参数
- DEMO 边界：只实现修正管线 + 1~2 个示例特性（如背刺），不做完整技能树

### 4.8 单位行动序列（已确认 2026-09-04）

```
移动 → 行动（攻击 / 法术 / 使用道具 / 待机）→ 再移动（可选）→ 确认朝向 → 结束
```

- **移动**：按移动力沿六边形移动，消耗地形移动成本
- **行动**：四类行动槽位——DEMO 按编成落地（攻击必做；治疗建模为法术；道具默认不实现，管线保留）
- **再移动**：行动后可再移动，**仅当单位支持**（兵种/特性授予，如火纹骑兵的再移动）；§5 兵种表将增加"再移动"标记；DEMO 简化（2026-09-04）：再移动使用完整移动力，剩余移动力规则留待 M6 平衡调整时定
- **确认朝向**：默认 = 最后一次移动或攻击方向，可手动调整（§4.7）
- **结束**：单位置灰，不可撤销
- 取消规则：移动/行动选择阶段允许撤销回退，进入下一阶段后不可回退（实现细节随 §7 UI 定）

### 4.9 技能系统（已确认 2026-09-04）

- 攻击类行动展开为：**选择技能 → 选择目标 → 结算**；伤害类型由技能声明（如剑盾战士："横斩"=挥砍、"盾突"=钝击）
- 兵种与装备决定**可用技能池**；法术归入技能系统（法术类技能=法术伤害，额外携带释放/生效配置，见 §4.12；治疗也是技能）
- 技能数据结构（纯配置）：`{ 名称, 伤害类型, 威力修正, 射程修正?, 特效? }`；特效走 §4.7 特性修正层同款管线
- DEMO 边界：每单位 2~3 个技能，无消耗无冷却（冷却/使用次数留作配置槽位，后续可启用）
- AI 择优：在"技能 × 目标"组合中选期望伤害最高者
- UI 影响：攻击流程多一步技能选择，战斗预报按所选技能显示矩阵克制与部位补正

### 4.10 辅助法术与护甲覆盖（已确认 2026-09-04）

- 单位战斗状态 = **兵种基础层 + 活跃法术效果列表**（每个效果带施加时间戳）
- **护甲类型解析**：存在活跃的护盾/护甲状态时，矩阵按其声明的护甲类型结算；无活跃效果时回落到兵种基础护甲（兵种绑定成为默认值）
- **护盾**：法术配置声明 `{ 护甲类型, 吸收量?, 持续? }`
  - 只改类型：如"轻灵咒"将目标护甲临时变为轻甲
  - 带吸收量：如"秘银护盾"= 中甲类型 + 吸收 10 点，伤害先扣护盾（按护盾类型过矩阵），破盾后回落兵种护甲
- **冲突规则**：同一判定维度上多个效果冲突时，**后生效覆盖先生效**（按施加时间戳取最新）
- 辅助法术是 §4.9 技能系统中的一种技能（伤害类型=法术、目标=友方、特效=施加状态），走同一条修正管线
- DEMO 边界：1~2 个示例辅助法术；状态系统只实现护甲覆盖与伤害吸收两种效果，不做完整状态机

### 4.11 飞行单位（已确认 2026-09-04）

- 飞行单位（如飞马骑士）：**无视地形通行限制与移动消耗差异**——所有格子按消耗 1 计算，可越山
- **可飞越、不可落被占格**（已确认 2026-09-04）：移动途中可穿过任何单位所在格，但移动终点不可选已被占据的格子；地面单位途经与落位均被阻挡
- 不享受所占地形的防御/回避加成（森林/基地的防与回避）；占据型效果（基地回血）照常生效
- 弓类技能特效"对飞行 ×1.5"（如技能"狙击"）——走技能特效修正管线，数值可配置；用于牵制飞行单位的高机动

### 4.12 法术机制：释放与生效（已确认 2026-09-04）

法术是技能（§4.9）的子类，额外携带**释放方式**与**生效方式**两个维度。

**释放方式**：

- **即时释放**：确认行动后立即触发
- **咏唱释放**：确认行动后进入咏唱状态，倒计时归零时触发
  - 倒计时按该单位所属阵营的阶段推进：确认当回合不计，己方新阶段开始 −1；归零时该阶段开始即触发结算，单位当回合恢复正常行动
  - **打断规则**：咏唱期间单位进行任何主动行动（移动、攻击、使用道具、释放其他法术）即打断，法术取消；受击**不打断**（默认，可被特性改写）；死亡则取消
  - 施法时锁定目标，触发时结算；咏唱期间目标死亡则法术落空取消

**生效方式**：

- **即时生效**：触发时一次结算（火球、治疗、施加护盾）
- **延时生效**：触发时在目标处挂计时器，每全局回合 −1，到点结算（如"咒杀"：3 回合后目标受 10 伤；目标死亡则落空）
- **持续生效**：触发时施加持续效果，每回合开始结算当回合效果直至到期（如"再生"：每回合回 5，持续 3 回合）；护甲覆盖类持续走 §4.10 状态系统

**组合矩阵与示例**：

| | 即时生效 | 延时生效 | 持续生效 |
| --- | --- | --- | --- |
| 即时释放 | 火球 / 治疗 / 秘银护盾 | 咒杀（3 回合后爆伤） | 再生（每回合回 5×3 回合） |
| 咏唱释放 | 陨石术（咏唱 2，高威力） | 预留 | 预留 |

- 法术数据结构（纯配置）：`{ 名称, 释放: {方式, 咏唱回合数?}, 生效: {方式, 延时/持续回合数?}, 效果, 射程, 目标类型 }`
- **法术威力**（已确认 2026-09-04）：配置 `power` 字段——治疗量/护盾吸收量/咒杀伤害 = 固定 power；伤害法术 = max(攻 + power − 防 − 地形防, 0) × 矩阵（普通技能 power 缺省 0，公式统一）
- **延时/持续计时**（已确认 2026-09-04）：延时与持续（含护盾持续）统一在**目标所属方阶段开始**推进——延时 −1 归零结算；持续结算当回合效果并 −1
- **施法距离**：基础 `[1, 2]`（可打相邻，无近身死角）；修正值走 §4.4 同款管线——来源：法术自身修正、属性条件（魔力阈值，如"攻 ≥9 施法距离 +1"）、装备、技能、状态
- **命中规则**：
  - 负面法术（伤害/减益，目标敌方）：走完整命中管线 `50 + 技×5 − 敌回避 + 部位补正 − 距离惩罚`，距离惩罚与弓同款（超出基础最大射程每格 −15）
  - 增益法术（治疗/护盾/增益，目标友方）：**必中**，不掷命中、不吃距离惩罚，但目标须在施法距离内
- 法术威力基数：DEMO 沿用「攻」属性（法系模板的攻值代表魔力），拆分独立「魔」属性留作扩展槽位
- UI：咏唱单位头顶图标 + 倒计时；预报/提示显示法术触发时点
- DEMO 边界：单体/单格法术，不做 AoE；示例 6 个（法师：火球/陨石术/咒杀；牧师：治疗/再生术/秘银护盾；敌方法师：火球）

## 6. 敌方 AI（已确认 2026-09-04）

- **激活规则**（按组配置，三种类型）：
  - **待机型**：警戒范围（移动+射程覆盖）内出现我方单位即激活；**被攻击时本人及所在组全组激活**（打一个引来一组）
  - **主动型**：登场即激活，从战斗开始就向我方推进进攻
  - **BOSS 特例**：固定驻基地不移动，我方进入其射程才攻击（经典火纹 BOSS 行为）
  - 激活后永久主动，不回归待机
- 组归属确认（2026-09-04）：**BOSS 单独成组**（boss 类型仅 BOSS 本人），北端卫队 B 为待机组，激活后可移动参战
- 激活配置确认（2026-09-04）：南线前哨 B（中路 3 人）为**主动型**，开场压制制造早期节奏；其余组待机，卫队与 BOSS 待机/驻守
- 全灭判定确认（2026-09-04）：场上敌方全灭**立即判胜**，未触发的增援事件作废（"增援计入敌方总数"指已登场增援计入）
- **决策逻辑**（激活单位，每回合）：
  1. 枚举"技能 × 目标 × 攻击落位"组合，**落位含部位考量**（能绕侧/绕背则优先）
  2. 能击杀的组合优先（期望伤害 ≥ 目标当前 HP）
  3. 否则选期望净收益最高：期望造成伤害 − 预期承受反击伤害
  4. 无可攻击目标 → 向最近我方单位移动，**保持组内集结**不散兵
- **表现**：敌方行动加短延时逐个播放，便于阅读
- **法术 AI**：敌方施法者只在目标处于射程内时施法；咏唱类法术仅当自身预计能存活到触发时选择（简化判定：当前 HP > 我方全场最高单次期望伤害则可用）
  - DEMO 边界（2026-09-04 确认）：敌方法师仅配即时火球，无咏唱法术——咏唱存活判定暂不实现，敌方模板配咏唱法术时再补
- **增援机制**：
  - 增援事件 = 配置项：`{ 触发条件, 刷新点, 增援单位列表, 次数 }`
  - 触发两类：回合数触发（如第 5 回合开始时）/ 条件触发（BOSS HP < 50%、某组被全灭、我方进入指定区域）
  - 刷新点为地图边缘配置的增援点（地图配置新增对象类型，见 §3）
  - 增援单位登场即激活（主动型）；胜利条件仍为敌方全灭，增援计入敌方总数
  - 表现：登场提示 + 出现动画
  - DEMO 建议（数值可配）：①第 5 回合东西两侧各刷 3 人（剑士/弓手）②BOSS HP < 50% 时北端刷 4 人锤兵卫队，均为一次性
- **DEMO 边界**：不做难度分级和协同包夹搜索；激活类型、增援事件、规则与权重全部可配置

## 7. UI 与交互（已确认 2026-09-04，原型见 docs/prototypes/main-battle.html）

### 7.1 布局

- 左侧地图画布（主区域），右侧固定宽信息面板
- 20×30 地图超出视口：**拖拽平移 + 滚轮缩放**；双击单位居中
- 顶部状态条：回合数、当前阶段（玩家/敌方）、胜负提示

### 7.2 单位操作流（对应 §4.8 行动序列）

1. 点选单位 → 蓝色移动范围（叠加红色攻击范围）
2. 点目标格 → 移动
3. 行动菜单：攻击（展开技能列表）/ 法术（展开法术列表）/ 待机
4. 选技能/法术 → 高亮射程内可选目标 → 点目标
5. 战斗预报面板：双方预计伤害×次数、命中率明细（部位/距离惩罚/矩阵克制）、是否反击 → 确认/取消
6. 再移动（单位支持时）
7. 确认朝向：显示默认朝向，点相邻格调整或直接确认
8. 单位置灰结束
- 撤销：移动/行动选择阶段可回退（右键/撤销按钮），进入下一阶段不可回退

### 7.3 信息面板

- 选中单位：名称、属性、护甲类型、技能池（含伤害类型）、特性、当前状态（护盾值/持续效果/咏唱倒计时）
- 光标格：地形类型与效果
- 悬停敌单位时：显示从当前选中单位的攻击部位（正/侧/背）与克制关系

### 7.4 战场反馈

- 伤害数字飘出、HP 条变化、阵亡淡出
- 咏唱图标 + 倒计时；延时/持续效果小图标 + 剩余回合
- 增援登场提示（边缘高亮 + 提示条）
- 敌方回合逐个行动播放，提供快进/跳过
- 胜负结算画面：回合数、双方存活统计
