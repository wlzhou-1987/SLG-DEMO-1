# 游戏设计文档 — 火纹式单场战斗 DEMO

> 状态：**M1 设计定稿 ✅**（2026-09-04）。M2~M6 已实现（见 §10）；后续设计变更经 `docs/BACKLOG.md` 流程回写本文。
> 数值与公式均为初版占位，以"先能玩、再调平衡"为原则。

## 1. 概述

- 类型：回合制战棋（SRPG），参考火焰纹章系列
- 一句话：一张 20×30 六边形地图上，我方 10 人部队歼灭敌方 40 人守军的单场战斗
- 体验目标：火纹式决策手感——查看移动范围 → 战斗预报 → 权衡风险 → 落子

## 2. 核心循环（已确认 2026-09-04）

- 战前准备阶段：进入战斗前配置我方出场名单与初始站位，确认开战后编成锁定，战斗内不可更改（详见 §7.0）
- 回合制：玩家阶段 → 敌方阶段 → 回合数 +1
- 单位行动 = 完整行动序列：移动 → 行动（攻击/法术/道具/待机）→ 再移动（单位支持时）→ 确认朝向 → 结束，详见 §4.8；已行动单位置灰
- 全部单位行动完毕自动进入敌方阶段，也可手动提前结束回合
- 胜利条件：敌方全灭
- 失败条件：我方全灭，或领主（主角）阵亡（见 §5.2）
- 无回合上限，战斗进行到分出胜负为止

## 3. 地图（已确认 2026-09-04）

- **正六边形网格**，尺寸 20×30（宽×高，配置项）
- 密度已验证：10+40=50 单位 / 600 格 ≈ 8.3%，落在火纹典型区间（7%~10%）
- 六边形朝向（尖顶/平顶）与坐标系（推荐轴坐标）为实现细节，工程初始化时定
- 距离、射程、移动范围均以六边形步数计
- 地形 4 种，**数据驱动定义，保留扩展性**（新增地形 = 新增一条配置，无需改代码）；效果字段显式平铺、消费点只读字段不认地形名（R6 定稿 2026-09-14；数值 R6-2 sim 校准定稿）：

| 地形 | 效果 | 移动消耗 |
| --- | --- | --- |
| 平原 | 无 | 1 |
| 森林 | 物理闪避 +20，物理防 +1，法术闪避 +10 | 2 |
| 山 | 不可通行 | - |
| 基地 | 物理防 +2，物理闪避 +20，法术防 +1，法术闪避 +20，回合开始恢复 10% 最大 HP 与 10 MP | 1 |

- **效果字段**（R6 定稿 2026-09-14，显式平铺、缺省 0）：物理防 / 法术防 / 物理闪避 / 法术闪避 / HP 回复（回合开始，按最大 HP 百分比）/ MP 回复（回合开始，固定值，无条件——不挂 MP 歇息的未施法判定；仅 MP 资源单位受益）/ 额外射程（只加最大射程、不抬最小射程）；本期 4 地形射程暂配 0，留未来高地/塔类地形
- **结算口径**：防/闪/射程在攻击结算与射程查询时即时读取；HP/MP 回复在**持有者阵营阶段开始**结算（与状态/资源推进同层同口径）；近战/远程防闪拆分与减益 5 项（回合开始直接伤害/降低护甲/降低魔防/增加 MP 消耗/回合结束附加 DoT）随新增特殊地形时按需扩展字段，结构不写死
- **移动消耗/通行挂点**（R8 移动阻碍登记）：`getMoveCost` 与寻路约束为扩展点，供单位光环叠加移动消耗/通行限制；无真实消费者不落逻辑（防战封锁走 Dijkstra 终点约束，不依赖此挂点）

- 基地效果**对任何驻守单位生效**（已确认）：北端布 1 处供敌方 BOSS 驻扎；我方占领后同样受益，形成"夺基"战术
- 敌方 40 人建议分 6~8 组待机型布防，玩家推进时逐组接敌（分组细节见 §5）；地图边缘含**增援点**（敌方增援刷新位置，见 §6）
- 关卡用静态 TS 配置文件定义，不做地图编辑器

## 4. 战斗机制（已确认 2026-09-04）

### 4.1 单位属性（8 项，R4 定稿 2026-09-07；主资源 R8 修订 2026-09-09）

| 属性 | 作用 |
| --- | --- |
| HP | 生命值，归零阵亡 |
| 力量 | 物理伤害基数（进入技能伤害段的属性权重表） |
| 魔力 | 魔法伤害/治疗基数（法术伤害段的单一基数属性） |
| 物防 | 物理线减伤（受地形物理防加成） |
| 魔防 | 魔法线减伤（× 魔防系数进入魔法段防御项） |
| 速 | 追击判定 / 回避驱动（× 速系数）/ 先攻反击阈值 / 部分技能伤害基数 |
| 技 | 命中基数；暴击率基数（R7 定稿 2026-09-14，§4.3）；弓手射程属性条件加成挂点 |
| 运 | 回避基数（× 运系数）；致命一击双向修正（R7 定稿 2026-09-14：攻方运 +1%/点、守方运 −1%/点，§4.3） |

- 主资源（R8 议题③定稿 2026-09-09）：每职业归属一种主资源——**怒气**（正面近战爆发系）/ **专注**（精准敏捷系）/ **MP**（法系）；枚举 `mp/rage/focus`（配置层可扩展），职业归属表见 §5；生成/消耗/恢复/上限结算见 §4.13（R5 设计定稿 2026-09-11）
- 死属性面（接受）：法系的力量、物理系的魔力、非本职业主资源（如物理职业的 MP）为当前死属性，为潜在转职激活预留；模板数值设计不为死属性付费
- 模板即职业（R8 设计定稿 2026-09-09；**JobConfig 实体化已落地 2026-09-17〔R2-4〕**）：`src/config/jobs.ts` 17 条与模板一一对应（id = 模板 id），承载职业级声明——**装备类别**（R2）/ **资源类型**（R5）/ **缺省权重**（R4，按伤害/效果线三支：物理 str×1、魔法 mag×1、治疗 mag×0.5，首版全职业共享基准、差异化留内容轮）；职业强化清单仍挂模板 traits；模板 weapons/resourceType 字段已删**防双真源**

### 4.2 克制体系：伤害类型 × 护甲 + 兵种标签（R4 定稿 2026-09-07；伤害类型来源 R8 修订 2026-09-09）

- 物理伤害 3 类：**斩**（原挥砍）/ **突**（原穿刺）/ **钝**（原钝击）；法术不再占矩阵行，走法术级克制（§4.12）；伤害类型的最终来源是**攻击时选择的技能或武器普攻**（§4.9：普攻伤害线由武器决定）——武器决定可学技能集（武器过滤，§4.9），**武器线不绑定单一伤害线**，伤害类型由技能自带（剑系可配突伤、斧系可配钝伤）
- 护甲 4 类不变：无 / 轻 / 中 / 重；由兵种模板携带（§5 落地），可被辅助法术效果临时覆盖（§4.10）
- **物理矩阵**（纯配置数据，系数可配、留平衡期调参；列序：无甲/轻甲/中甲/重甲；只看伤害类型 × 护甲、不考虑距离）：

| 伤害 \ 护甲 | 无甲 | 轻甲 | 中甲 | 重甲 |
| --- | --- | --- | --- | --- |
| 斩（泛用武器） | 1.2 | 1.0 | 1.0 | 0.7 |
| 突（软目标应对） | 1.3 | 1.2 | 0.8 | 0.6 |
| 钝（破甲应对） | 0.8 | 0.8 | 1.0 | 1.4 |

- 设计原则：**武器 = 应对卡**——梯度取代旧版离散三角（每行恰一个 ×1.25/×0.75）；行和均衡（3.9/3.9/4.0，总收益接近，选武器 = 选应对对象）；列和单调递减（3.3→3.0→2.8→2.7，护甲价值方向一致）；斩随护甲平缓、突随护甲递减、钝随护甲递增
- **兵种标签**：UnitTemplate 挂 unitTags 数组，标签集 = 骑兵 / 飞行 / 重甲 / 步兵 / 魔物 / 龙（可扩展，未来可配针对性武器如屠龙/反步兵）；步兵为显式标签；支持多标签（重甲骑兵等）；原 flying 布尔收编为「飞行」标签（含该标签即按 §4.11 飞行移动规则处理）
- **兵种克制**：技能/装备级 counters 配置（`Partial<Record<UnitTag, number>>`，缺省 1、允许 < 1），物理魔法通用
- **克制合成**：克制系数 = 护甲克制 × ∏(适用兵种克制)，全局上限可配（默认 ×3.0）；只进伤害乘区、不影响命中回避（与矩阵行为一致）
- 矩阵与 counters 均可被特性改写（如"破甲"特性无视克制）
- 标签映射与落值见 §5；原则：每个标签至少一个携带者或明确内容计划；魔物/龙纯预留
- UI：战斗预报分列护甲克制与兵种特效明细（§4.5）；单位面板显示兵种标签（§7.3）

### 4.3 战斗公式（R4 定稿 2026-09-07：统一伤害结构、双轴回避、先攻反击；乘数总封顶 R8 增补 2026-09-09）

**统一伤害结构**：

- 物理 / 魔法 / 治疗共用「**伤害段**」结构 `{ 属性权重表, 固定值, 伤害线 }`；技能与法术配置段数组（段数组支持多段；R8 实例化双伤害段：强化旋风斩第二段减半，§5.1），不维护两套公式
- 法术为伤害段的单属性特例：权重 `{ 魔力: 法术伤害系数 }` + 法术固定伤害
- 技能伤害基数（组合权重）：技能配置属性权重（如 `{技巧: 1, 速度: 0.5}`）加权合成；减伤轴由**伤害线**决定（物理线 → 物防、魔法线 → 魔防），与基数属性解耦；未配置时取职业缺省权重（JobConfig.defaultWeights 按线三支，R2-4 实体化；首版全职业基准 = 物理 str×1 / 魔法 mag×1 / 治疗 mag×0.5）

**统一伤害公式**：

- 伤害 = max( ((Σ 属性 × 权重) + 固定值) × 克制系数 − 防御项 − 地形防, 0 )；克制乘算位于 max 内（先乘后减）；**取整规则（R4-2 实现定稿 2026-09-11）**：全链浮点计算，最终结果 floor，部位伤害加算（背面 +3）在 floor 后加算
- 物理段：防御项 = 物防，地形防 = 地形物理防，克制系数 = 护甲矩阵 × ∏兵种克制（§4.2）
- 魔法段：防御项 = 魔防 × 魔防系数（默认 1，可被职业/被动技能修正，预留挂点），地形防 = 地形法术防，克制系数 = 法术级克制（§4.12）
- 治疗段：同结构、不扣防御项与地形防；治疗量按技能差异化公式，主要挂魔力
- 法术直接伤害 = max((魔力 × 法术伤害系数 + 法术固定伤害) × 法术级克制 − 魔防 × 魔防系数 − 地形法术防, 0)
- DoT 每回合伤害 = max(1, floor(直接结果 ÷ 持续回合数))，末回合补足余数（此前合计不足直接结果时补差）；max(1,·) 保底与系数调参带来的小幅总伤溢价为接受设计（意图：DoT 总伤略高于同位直伤、每回合不跳 0）；**施放时锁定**每回合伤害、存入状态按存值跳（预报 = 实际）
- **全局伤害倍率总封顶**（R8 议题⑤评审定稿 2026-09-09，随 R4 落地）：单次攻击全部乘数（暴击、狂战线性、冲锋线性、特效克制、破隐加成等）联乘后的总倍率设上限（候选 ≤4.0，可配，超限截断）；克制合成上限（§4.2 默认 ×3.0）约束克制乘区自身，总封顶为最外层兜底，两层并存

**命中与回避（双轴）**：

- 回避分物理/法术两轴：回避 = 速 × 速系数 + 运 × 运系数 + 对应线地形闪避；两轴四系数独立可配（两轴默认同值；**R4-8 定稿 2026-09-11：速系数 3 / 运系数 3**——回避 = (速+运)×3，速作为高价属性主导闪避）；法术线地形闪避 = 地形法术闪避字段（R6-1 落地；森林法闪 10/基地 20 定稿，§3）
- 回避纳入修正管线可改写项（装备/技能/特性，无需新机制）
- 命中率 = clamp(50 + 技 × 5 − 对应轴回避 + 部位补正 − 距离递增惩罚, 5, 100)（结构不变；克制不影响命中保持）；增益法术必中保持（§4.12）

**暴击（致命一击）（R7 设计定稿 2026-09-14）**：

- 暴击率 = clamp(攻技 × 1 + (攻运 − 守运) × 1 + 修正合计, 0, 暴击上限) + 武器暴击加成，最终 clamp(·, 0, 100)；参数 `critPerTech` / `critPerLck` / `critCap` / `critAbsMax`（1 / 1 / 50 / 100）进 COMBAT_PARAMS；修正合计走 §4.7 特性修正管线（鹰眼溢出转换等）；技入攻侧 = 命中饱和后的第二次定价，守方防暴只看运
- 暴击上限 = 50 + Σ `critCapBonus`（技能/特性**显式声明**，逐技能设计决定能否突破；首版消费者 = 瞄准射击蓄力触发一击 +20）；**武器暴击加成在 clamp 外自动全额生效**（仅受 100 绝对顶，装备品级语义无需配对声明；作用域 = 持有者全部攻击〔普攻 + 该武器线技能 + 法术〕；**R2 落地 2026-09-15**：`critBonus` 挂武器条目、装备条目求和（§4.14，R2-3 接管线），R7 过渡期按原子的全局表 WEAPON_CRIT_BONUS 已随 R2-3 退役）
- **命中溢出转暴击**（鹰眼被动，弓箭专属）：溢出 = 命中率全修正 **clamp 前原值 − 100**（鹰眼自身 +30 命中参与喂溢出），1:1 进修正合计、限远程；溢出只对低回避目标产生（「狙击手惩罚站桩靶」定向性公式自带）
- **必暴 `critOverride`**（致命突袭/空中突袭，R8 声明先行兑现）：绝对层——不掷骰、技运均不参与、直接 ×2
- 掷骰口径：**逐击独立掷暴**（攻方攻击/反击/追击/先攻反击，公式攻守按该次攻击代入）；先掷命中、命中落地才掷暴击；直击法术可暴（同一公式）、治疗/增益不暴；持续类（DoT/再生）施放时锁定、永不掷暴（预报 = 实际）；×2 进乘数区联乘后吃全局总封顶（见上文）
- 暴击资源（§4.13 联动）：出手方暴击且主资源 = 怒气时额外 +15；专注/MP 系暴击无额外资源收益
- AI 与反击择优：期望伤害 = 命中率 × (非暴击伤害 × (1−暴击率) + 暴击伤害 × 暴击率)，AI 择优与反击技能择优同步使用（§6）。R7-1 落地时由简化式「命中率 × 伤害 × (1+暴击率)」收正：防御后置使暴击伤害 ≠ 2×非暴击伤害，简化式在「0 伤可被暴击翻出」场景把期望算成 0，与本节该设计自相矛盾
- 显示：战斗预报加暴击率行（§4.5）；战报记「暴击！」；飘字暴击标记；单位面板不加行（暴击率是对局相关值）

**追击与先攻反击**：

- 追击：速度差 ≥ 4 时速度快的一方多攻击一次（不变）
- **先攻反击**：守方速度超出攻方 ≥ 阈值（暂定 10，可配）时，被攻击的反击先于攻方攻击结算；阈值可被技能强化降低（如降至 5）
- 结算顺序：先攻反击（触发时）→ 攻方攻击 → 守方反击 → 追击；先攻反击击杀攻方则其攻击不发生
- 反击技能选择：守方有多个技能射程覆盖攻方位置时，取期望伤害最高者（与 §6 AI 择优一致，不变）
- 近战/远程判定（定稿、暂缓实现）：仅对物理伤害与物理技能生效，按攻击发生时双方距离判定（距离 1 = 近战、≥2 = 远程）；法术线不区分近远程；当前无消费者，待首个真实消费者（装备；R6 近远地形拆分已随特殊地形推迟）出现再落逻辑
- 实际结算按命中率掷随机数；战斗预报显示概率而非结果（不变）

### 4.4 射程与距离惩罚（R4 定稿 2026-09-07：条件加成归属、递增惩罚；普攻射程与动态射程 R8 增补 2026-09-09）

- 射程统一建模为区间 `[最小射程, 最大射程]` = **基础值 + 修正值**（结构不变）
  - 基础值：技能配置值——近战 `[1,1]`，弓手基础 `[2,2]`；**普攻基础射程 = 武器条目普攻段**（§4.14 装备条目；UnitTemplate 过渡口径随 R2 退役）
  - 修正值：走 §4.7 特性修正管线；来源包括武器/装备加成、**属性条件加成**、**地形额外射程**（R6 定稿 2026-09-14：即时读取、飞行不享受、只加最大射程）、特性、技能特效、状态
- **属性条件加成**（原留白定稿）：弓挂**力量**、法术挂**魔力**，阈值规则可配（如"力量 ≥ 9 时射程 +1"）
- **距离命中惩罚改递增制**：第 n 个超程格的惩罚 = 基础值 + 递增值 × (n−1)，累计求和（参数可配；**R4-8 定稿 2026-09-11：基础 15 / 递增 10**）；近战恒为 0，规则自然退化无需特判
- 基础射程 = 技能配置值；属性/地形加出的**延伸格同样吃距离命中惩罚**（与弓手价值分配闭环）；物理远程与负面法术同款
- 弓手属性价值分配方向：技供命中、实际射程越远命中惩罚越高、命中溢出 100% 部分转暴击（换算 1:1 进暴击修正合计、限远程——R7 定稿 2026-09-14，见 §4.3）
- 弓手最小射程保持 2：相邻格仍是攻击/反击死角（贴脸克制不变）
- 动态射程（R8 定稿 2026-09-09；R12-2 落地 2026-09-23）：射程修正可由特性按属性动态给出——治疗/增益法术（targetType=ally）在施法者持「强化治疗」特性且**技 ≥ 16** 时射程 +1（RANGE_PARAMS.healTecThreshold 可配；与魔力阈值射程按加法合计——牧师终战档 ally 法程 2+1+1=4；敌方无此特性天然不吃）
- 战斗预报显示当前攻击距离与惩罚值（不变）

### 4.7 朝向与部位系统（已确认 2026-09-04；修正维度 R8 扩展 2026-09-09）

**基础规则层**（默认生效，全部可被特性修正）：

- 每个单位恒有一个朝向，指向相邻 6 格之一
- 朝向控制（已确认 2026-09-04）：行动序列末尾有"确认朝向"步骤，**默认朝向 = 最后一次移动或攻击的方向，玩家可手动调整**；此为基础规则，可被特性改写
- 以**守方朝向**为基准，攻击者所在格分三区：
  - 正面 3 格：朝向格 + 左右紧邻两格（180° 扇面）
  - 侧面 2 格：侧后方两格
  - 背面 1 格：正对背后
- 部位补正默认值：

| 攻击来自 | 命中 | 伤害 |
| --- | --- | --- |
| 正面 | — | — |
| 侧面 | +10 | — |
| 背面 | +25 | +3 |

- 远程攻击（射程 2）同样按守方朝向判部位；**远程部位判定**（已确认 2026-09-04）：攻方相对守方的方向量化到最近 6 方向后，再按正/侧/背扇区判定
- 被攻击**不自动转向**（默认）
- 反击、追击套用同一部位规则（默认）
- AI 同样利用部位补正择优攻击
- UI：单位绘制朝向箭头，战斗预报显示部位及补正

**修正层——特性系统**（扩展机制）：

- "特性"是技能/天赋/道具的统一抽象，挂在单位身上，战斗结算时逐条应用
- 基础规则层的每一项（补正数值、是否自动转向、反击是否套用等）都可被特性改写
- 特性类型举例：
  - 数值改算：被动「低血狂战」——威力随 HP 降低线性提升（斧兵，§5.1）
  - 行为改写："警觉"——被攻击时自动转向攻击者，侧/背攻击对其失效
  - 补正减免："沉稳"——受到的部位命中补正减半
- 特性可改写维度扩展（R8 定稿 2026-09-09）：**范围判定**（光环——以持有者为中心的范围持续属性增益，如领主被动）；**判定参数改写**（部位判定函数参数化——如防战「防御姿态」期间仅正后 1 格算背面）；**移动阻碍**（如防战被动使敌方不可经过其身边、只能逐格挪；挂点与 R6 地形移动消耗同构，R6 设计承接）
- 结算管线：取基础规则 → 依攻守双方特性逐条修正 → 得最终结算参数
- DEMO 边界（R8 修订 2026-09-09）：实现修正管线 + §5 首版清单的被动/职业强化，不做完整技能树

### 4.8 单位行动序列（已确认 2026-09-04；普攻/瞬发/再移动技能化 R8 修订 2026-09-09）

```
移动 → 行动（攻击 / 法术 / 使用道具 / 待机）→ 再移动（可选）→ 确认朝向 → 结束
```

- **移动**：按移动力沿六边形移动，消耗地形移动成本
- **行动**：攻击（**普攻或技能攻击**，§4.9）/ 法术（技能系统中法术类技能，§4.12）/ 使用道具（默认不实现，管线保留）/ 待机
- **瞬发动作**（R8 新增概念，2026-09-09）：技能可声明「瞬发」（如斧兵嗜血）——释放后本回合行动不结束，可继续移动/攻击/使用技能；重复约束随技能声明（嗜血状态期内不可再次瞬发嗜血）
- **再移动**：行动后可再移动，由被动技能「再移动」授予（R8 技能化 2026-09-09，模板 reMove 字段随 R3 迁移删除，§5.1）；**剩余移动力规则（定稿 2026-09-04，M6-4）**：再移动范围 = 移动力 − 本回合已消耗移动力（按地形代价累计，撤销移动时返还；阶段开始重置）。满移动力冲锋后无法再移动
- **确认朝向**：默认 = 最后一次移动或攻击方向，可手动调整（§4.7）
- **结束**：单位置灰，不可撤销
- 取消规则：移动/行动选择阶段允许撤销回退，进入下一阶段后不可回退（实现细节随 §7 UI 定）

### 4.9 技能与职业体系（R8 重写定稿 2026-09-09，原「技能系统」）

**基础攻击（普攻）——角色固有能力，非技能**：

- 不占技能位、不耗资源；伤害按武器 × 护甲矩阵计算，伤害线/威力/射程为**武器条目普攻段数据**（§4.14；UnitTemplate 过渡口径随 R2 退役）
- 普攻积攒主资源（怒气/专注/MP，§4.13）；法系（杖）普攻 = 低威力钝伤杖击（保底手段 + MP 积攒途径，法系输出靠法术）
- 原基础攻击技能（横斩/突刺/重劈/射击）删除，被武器普攻吸收；普攻即保底，学习槽不设保底校验

**技能组织——三注册表并列**：

- **SKILLS**：物理攻击技能 + 行为技能（主效果为行为段的主动技能，如潜行、冲杀）
- **SPELLS**：法术（额外携带释放/生效配置，§4.12）
- **TRAIT_CONFIGS**：被动技能 + 职业强化（复用 §4.7 特性修正管线）
- 通用技能池 = 三表可学条目的 **union 视图**（合并枚举函数），不建统一单表

**技能三分类**（叠加生效）：

- **主动技能**（可配置）：进通用池，占主动技能槽
- **被动技能**（可配置）：TRAIT_CONFIGS 标 learnable=true 进通用池，占被动技能槽
- **职业强化**（职业技能，绑定职业不可选、确认职业即确定）：对通用技能的强化改写（可改写主效果或追加附属段），learnable=false 仅模板引用；每职业可多条（结构支持 N，首版内容见 §5）

**技能数据结构**（纯配置）：

- 主动技能：`{ 名称, target: 'enemy'|'self'|'ally', 主效果, 附属段?, 射程?, 效果区域?, resourceType?, weaponType?, counters?, 特效?, 瞬发? }`
- **效果声明 = 1 主效果 + 封闭附属段**：主效果有且仅 1（伤害/治疗/状态施加/行为四段之一；伤害主效果用 §4.3 伤害段结构，未配权重取职业缺省；治疗与状态段复用法术现有结构）；附属段按时间点封闭枚举三种——**独立资源段**（即时结算，如战斗怒吼主=范围增益、附=自身回怒气）、**状态段 onTurnStart**（持续期每回合结算，如强化祝福）、**伤害段 onHit**（命中瞬间，如强化火球附加灼烧）；纯资源技能暂不允许，新附属类型经新机制流程评估扩枚举
- **AoE 效果区域**（技能/法术可选声明，缺省单体）：形状枚举 disc（圆盘）/ sector（朝向扇形，取施法者朝向）；叠加于 target 维度（enemy+area=敌方群体、ally+area=群体治疗）；**目标选择 = 选释放位置（格子）而非单位**——射程按施法者到中心格计、空格可释放，区域内**只影响目标阵营**、逐单位独立命中结算；AoE 法术不触发反击
- target=ally/self 必中（不掷命中、不吃距离惩罚，§4.12 增益口径）

**潜行机制**（行为技能实例，R8 议题④定稿 2026-09-09）：

- **绝对隐身**：对敌阵营不可见、不可选中为单体目标；AoE 区域筛受影响者时直接排除（无邻格/侦查发现判定）
- **取消时机 = 三类主动行为**（移动/攻击/使用技能）即取消；**歇息不取消、跨回合维持**（潜行蹲草回资源玩法成立）
- 潜行单位仍占格：不可经过、不可停留、不可落位（复用单位阻挡逻辑）；规则对称、首版不配敌方潜行；AI 交互与真实视野反制见 §6
- 职业例外（§5.1）：强化潜行（移动不破隐）、隐秘猎手（蓄力射击不破隐）

**可学性——双过滤**：

- **资源过滤**（仅主动技能）：声明 `resourceType` 的技能只能配置给主资源对应的职业（战士无 MP，火球不可选）；未声明资源与全部被动豁免——死配置接受（如无 MP 职业装回 MP 被动不生效），属配置者自担，不校验拦截
- **武器过滤**（声明即过滤，主动被动均适用）：声明 `weaponType`（单值或 one-of 数组，如横扫=['锤','斧']）的技能，所需 ∈ 角色装备武器原子并集（§4.14 双槽条目并集，R2-3 起生效；UnitTemplate.weapons 过渡口径已退役）才可配置；未声明豁免；法术默认免武器声明

**武器**：

- 武器原子 8 种：剑 / 盾 / 锤 / 匕首 / 枪 / 斧 / 弓 / 杖；角色武器 = 原子数组，**任意组合合法**（剑盾、锤盾、单原子等），不设组合白名单，组合由装备类别与装备配置自由决定；具体武器条目、槽位与装备规则见 **§4.14 装备系统（R2）**

**槽位与装填**：

- 主动技能槽 0~5（上限 5 考虑法术多样性；下限随保底校验取消可至 0，实现期定）、被动技能槽 0~6（允许全清）；全局统一可配常量
- 出厂默认装填 = 特色技能 + 绑定被动；学习槽玩家可在战前准备中修改（§7.0，R3 落地）；冷却/使用次数留作配置槽位（后续可启用）
- 敌方技能配置：落点 = 关卡敌方单位条目（可选字段），默认通用模板仅带职业强化（R8 首版内容不配，§5.2）；配置受资源 + 武器双约束校验

- AI 择优：在「技能 × 目标 × 攻击落位」组合中选期望伤害最高者，**含普攻**（纯普攻单位同规则，§6）
- UI 影响：攻击流程含攻击方式选择（普攻/技能），战斗预报按所选方式显示矩阵克制与部位补正

### 4.10 辅助法术与护甲覆盖（已确认 2026-09-04；状态边界 R8 修订 2026-09-09）

- 单位战斗状态 = **兵种基础层 + 活跃法术效果列表**（每个效果带施加时间戳）
- **护甲类型解析**：存在活跃的护盾/护甲状态时，矩阵按其声明的护甲类型结算；无活跃效果时回落到兵种基础护甲（兵种绑定成为默认值）
- **护盾**：法术配置声明 `{ 护甲类型, 吸收量?, 持续? }`
  - 只改类型：如"轻灵咒"将目标护甲临时变为轻甲
  - 带吸收量：如"秘银护盾"= 中甲类型 + 吸收 10 点，伤害先扣护盾（按护盾类型过矩阵），破盾后回落兵种护甲
- **冲突规则**：同一判定维度上多个效果冲突时，**后生效覆盖先生效**（按施加时间戳取最新）
- 辅助法术是 §4.9 技能系统中的一种技能（伤害类型=法术、目标=友方、特效=施加状态），走同一条修正管线
- DEMO 边界（R8 修订 2026-09-09）：状态效果为**封闭枚举**——护甲覆盖、伤害吸收、属性增益/减益（可声明随回合衰减）、姿态、DoT、隐形、咏唱/蓄力；新增状态类型经新机制流程评估后扩枚举；不做完整状态机（状态间交互/互斥规则不展开）

### 4.11 飞行单位（已确认 2026-09-04）

- 飞行单位（如飞马骑士；判定口径 R4：unitTags 含「飞行」标签即飞行单位，收编原 flying 布尔）：**无视地形通行限制与移动消耗差异**——所有格子按消耗 1 计算，可越山
- **可飞越、不可落被占格**（已确认 2026-09-04）：移动途中可穿过任何单位所在格，但移动终点不可选已被占据的格子；地面单位途经与落位均被阻挡
- 不享受所占地形的**加成型**效果——防御/回避/额外射程（R6 定稿 2026-09-14：射程与防/闪同归加成型）；**占据型**效果（HP/MP 回复）照常生效
- 弓类技能特效"对飞行 ×1.5"（如技能"狙击"）——R4 起为技能级 counters 配置（§4.2），数值可配置；用于牵制飞行单位的高机动

### 4.12 法术机制：释放与生效（已确认 2026-09-04；AoE/衰减/蓄力/通用池 R8 修订 2026-09-09）

法术是技能（§4.9）的子类，额外携带**释放方式**与**生效方式**两个维度。

**释放方式**：

- **即时释放**：确认行动后立即触发
- **咏唱释放**：确认行动后进入咏唱状态，倒计时归零时触发
  - 倒计时按该单位所属阵营的阶段推进：确认当回合不计，己方新阶段开始 −1；归零时该阶段开始即触发结算，单位当回合恢复正常行动
  - **打断规则**：咏唱期间单位进行任何主动行动（移动、攻击、使用道具、释放其他法术）即打断，法术取消；受击**不打断**（默认，可被特性改写）；死亡则取消
  - 施法时锁定目标，触发时结算；咏唱期间目标死亡则法术落空取消
  - **蓄力**（R8 定稿 2026-09-09）：咏唱结构可被物理技能复用为**蓄力**（如弓手「瞄准射击」：蓄力 1 回合后攻击，额外伤害、命中免距离惩罚、触发时不受射程限制）

**生效方式**：

- **即时生效**：触发时一次结算（火球、治疗、施加护盾）
- **持续生效**：触发时施加持续效果，每回合开始结算当回合效果直至到期（如"再生"：每回合回 5，持续 3 回合）；伤害类持续（DoT）每回合伤害于施放时锁定（公式见 §4.3，预报 = 实际；如"咒杀"：3 回合每回合伤害，R10 定稿 2026-09-14——原「延时后单次爆伤」改为 DoT，与灼烧同构一套规则）；护甲覆盖类持续走 §4.10 状态系统；持续参数可声明**随回合衰减**（R8，如防骑祝福：魔防增益逐回合递减）
- ~~延时生效~~ **「延时生效」模式退役（R10 定稿 2026-09-14）**：effectMode 枚举删除 `delayed`；原唯一消费者咒杀迁往持续生效（DoT），「目标先死则落空」特殊规则随之删除（逐回合结算天然逐段生效）

**组合矩阵与示例**：

| | 即时生效 | 持续生效 |
| --- | --- | --- |
| 即时释放 | 火球 / 治疗 / 秘银护盾 | 再生（每回合回 5×3 回合）/ 咒杀（DoT 3 回合逐回合伤，R10） |
| 咏唱释放 | 陨石术（咏唱 2，高威力，AoE 圆盘 §4.9） | 预留 |

- 法术数据结构（纯配置，R4 口径；R10 修订 2026-09-14）：`{ 名称, 释放: {方式, 咏唱回合数?}, 生效: {方式, 持续回合数?}, 效果（含法术伤害系数/固定伤害、对护甲克制系数、counters）, 射程, 目标类型 }`

### 4.14 装备系统（R2 设计定稿 2026-09-15）

**范围**：仅武器装备——物品（战斗内消耗品道具）维持 §8「不做、管线保留」，不做携带结构；护甲/防具仍绑兵种模板（§4.2）不入装备面；装备随编成战前锁定（§2），战斗内不可换装。

**武器条目**（纯配置，注册表 `src/config/weapons.ts`，首版 15 条）：

- 数据结构：`{ id, 名称, 原子, 伤害线?, 威力?, 射程?, critBonus?, counters? }`；伤害线 + 威力 + 射程 = **普攻段**，齐备才供普攻形态——**未配普攻段的条目不供普攻**（盾条目 = 纯原子供体，不设盾特判）
- 差异化维度与边界：**威力** = 每原子基准值（剑2/枪2/斧3/锤3/匕1/弓1/杖0，进普攻伤害段固定值 §4.3——钝/斧重器补无甲弱项、匕/弓轻器由属性补）；**必杀型** = critBonus +10、威力 −2（匕/弓基准 1 → −1）；**特效** = counters 装备级（§4.2）；**跨线条目** = 同原子换伤害线（§4.2「武器线不绑伤害线」的装备层兑现，如刺剑=剑·突）；**品级维度（铁/钢/银）不做**——DEMO 无经济/熟练度约束，自由换装下纯威力梯度单调退化（人人选最高档），阵营强度差由八维属性表达（§5）；命中取舍与射程差异首版不开（后续内容轮追加配置字段，不动结算管线）；条目无实例状态（无耐久 §4.6、无强化、无库存唯一性，多人可引用同条目）

## 6. 敌方 AI（已确认 2026-09-04；R8 修订 2026-09-09：普攻择优与潜行交互）

- **激活规则**（按组配置，三种类型）：
  - **待机型**：警戒范围（移动+射程覆盖）内出现我方单位即激活；**被攻击时本人及所在组全组激活**（打一个引来一组）
  - **主动型**：登场即激活，从战斗开始就向我方推进进攻
  - **BOSS 特例**：固定驻基地不移动，我方进入其射程才攻击（经典火纹 BOSS 行为）
  - 激活后永久主动，不回归待机
- 组归属确认（2026-09-04）：**BOSS 单独成组**（boss 类型仅 BOSS 本人），北端卫队 B 为待机组，激活后可移动参战
- 激活配置确认（2026-09-04）：南线前哨 B（中路 3 人）为**主动型**，开场压制制造早期节奏；其余组待机，卫队与 BOSS 待机/驻守
- 全灭判定确认（2026-09-04）：场上敌方全灭**立即判胜**，未触发的增援事件作废（"增援计入敌方总数"指已登场增援计入）
- **决策逻辑**（激活单位，每回合）：
  1. 枚举「**普攻 × 技能** × 目标 × 攻击落位」组合（纯普攻单位同规则，§5.2 三杂兵），**落位含部位考量**（能绕侧/绕背则优先）
  2. 能击杀的组合优先（期望伤害 ≥ 目标当前 HP）
  3. 否则选期望净收益最高：期望造成伤害 − 预期承受反击伤害
  4. 无可攻击目标 → 向最近我方单位移动（**不计潜行单位**，见下），**保持组内集结**不散兵
- **潜行交互**（R8 议题④定稿 2026-09-09）：
  - **感知全忽略 + 物理存在保留**：警戒扫描不含潜行单位；择优不可选为目标（含攻击落位计算）；「向最近我方单位移动」不计潜行单位
  - 潜行单位**仍占格**：不可经过、不可停留、不可落位（复用单位阻挡逻辑，潜行封路战术成立）；寻路遇潜行占格致无可达路径的 fallback 随 R3 落地处理
  - **真实视野反制**：持有者（revealRange N）周围 N 格内，潜行单位对**持有者所在阵营**可见、可选中攻击，潜行状态**不取消**（出范围自动重新隐匿）；敌方持有真实视野时，其警戒/择优对范围内潜行单位按普通单位处理（§5.2 首版至少 2 处独立布防）
  - **规则对称**：潜行语义对任意阵营一致（敌方若潜行则对我方隐藏渲染、不可选中）；首版 17 模板不配敌方潜行
- **表现**：敌方行动加短延时逐个播放，便于阅读
- **法术 AI**：敌方施法者只在目标处于射程内时施法；咏唱类法术仅当自身预计能存活到触发时选择（简化判定：当前 HP > 我方全场最高单次期望伤害则可用）
  - DEMO 边界（2026-09-04 确认）：敌方法师仅配即时火球，无咏唱法术——咏唱存活判定暂不实现，敌方模板配咏唱法术时再补
- **增援机制**：
  - 增援事件 = 配置项：`{ 触发条件, 刷新点, 增援单位列表, 次数 }`
  - 触发两类：回合数触发（如第 5 回合开始时）/ 条件触发（BOSS HP < 50%、某组被全灭、我方进入指定区域）
  - 刷新点为地图边缘配置的增援点（地图配置新增对象类型，见 §3）
  - 增援单位登场即激活（主动型）；胜利条件仍为敌方全灭，增援计入敌方总数
  - 表现：登场提示 + 出现动画
  - DEMO 建议（数值可配）：①第 5 回合东西两侧各刷 3 人（剑士/弓手）②BOSS HP < 50% 时北端刷 4 人锤兵卫队，均为一次性
- **DEMO 边界**：不做难度分级和协同包夹搜索；激活类型、增援事件、规则与权重全部可配置

- 选中单位：名称、属性（八维 + 主资源，§4.1）、装备（武器条目名，§4.14，R2-5 落地）、护甲类型、兵种标签（R4）、已装技能（主动/被动分列）、当前状态（护盾值/持续效果/咏唱或蓄力倒计时/**潜行**）
- 光标格：地形类型与效果
- 悬停敌单位时：显示从当前选中单位的攻击部位（正/侧/背）与克制关系

### 7.4 战场反馈

- 伤害数字飘出、HP 条变化、阵亡淡出
- 咏唱图标 + 倒计时；延时/持续效果小图标 + 剩余回合
- 潜行单位对不可见阵营隐藏渲染（真实视野范围内显形，§6）
- 增援登场提示（边缘高亮 + 提示条）
- 敌方回合逐个行动播放，提供快进/跳过
- 胜负结算画面：回合数、双方存活统计
