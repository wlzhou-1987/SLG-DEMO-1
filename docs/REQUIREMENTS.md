# 需求文档

> 状态：**历史定稿存档**（2026-09-04 定稿，范围界定仍有效；里程碑表已被取代）。详细设计见 [GAME-DESIGN.md](GAME-DESIGN.md)。

## 一句话描述

火纹式单场战斗：我方 10 人部队在一张 20×30 六边形地图上歼灭敌方 40 人守军的回合制战棋 DEMO。

## 游戏类型与核心玩法

- 类型：回合制策略战棋（SRPG），参考火焰纹章系列
- 核心循环：玩家阶段（逐单位移动+攻击/待机）→ 敌方阶段（AI 行动）→ 回合 +1，循环至胜负判定
- 胜负：歼灭全部敌人获胜；我方全灭失败；无回合上限
- 体验目标：火纹式决策手感（移动范围、战斗预报、风险权衡）

## DEMO 范围边界

- 包含：单张 20×30 正六边形网格地图（尺寸可配置）、4 兵种、武器三角、地形效果、反击/追击、战斗预报、基础敌方 AI、胜负判定
- 不包含：成长/升级/转职、剧情对话、武器耐久、道具、存档、音效音乐、暴击、多地图

## 平台与运行方式

- 目标平台：浏览器（本地 dev server 或构建后静态页面）——随技术栈确认
- 运行方式：网页打开即玩，键鼠操作

## 素材来源

- 无外部素材：单位用色块 + 兵种首字渲染，地形用纯色/纹理区分
